# Project Overview

AI Kindergarten Uniform Recycling System is a prototype for managing kindergarten uniform reuse. It helps schools collect anonymized uniform information, estimate wear level from uploaded images, and track circulation status.

## Goals

- Support uniform recycling and reduce waste.
- Provide a simple OpenCV-based wear-level estimate.
- Store traceable records in SQLite.
- Give administrators a foundation for review, filtering, and status updates.

## Privacy Principle

The repository must contain only virtual test data. Do not commit real children's information, contact details, school identity data, or real photos.
